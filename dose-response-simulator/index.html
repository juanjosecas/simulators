The 4PL equation used by this simulator

Four-parameter logistic model
Response(d) = Bottom + (Top − Bottom) / [1 + (EC50 / d)Hill]
At d = EC50, the predicted response is exactly halfway between Bottom and Top: Bottom + (Top − Bottom)/2.
BottomEmin

Lower asymptote of the fitted response. Pharmacologically, it can represent basal activity, background signal, or the minimum attainable effect.

Increase it: the lower plateau moves upward.
Top / EmaxEmax

Upper asymptote. In a stimulatory concentration-response experiment it represents the maximal effect supported by the system and assay.

Increase it: the upper plateau rises; efficacy increases.
EC50EC50

Concentration producing 50% of the fitted dynamic range between Bottom and Top. It is a measure of apparent potency, not receptor affinity by itself.

Lower EC50: curve shifts left → greater potency. Higher EC50: shifts right.
Hill slopenH

Controls how abruptly response changes around EC50. In this implementation positive values describe increasing curves and negative values decreasing curves.

Larger |Hill|: steeper transition. It should not automatically be interpreted as a stoichiometric binding coefficient.
